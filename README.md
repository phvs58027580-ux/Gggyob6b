# Pocket World 3D — Dual Capture
Protótipo Three.js/Vite com captura dupla: captura livre no mundo + captura tradicional em batalha.

## Captura livre
Aproxime-se de uma criatura e use E/C (ou 🎯 no celular). O protótipo considera se ela está de costas/distraída e pode fazê-la fugir. Você também pode escolher entrar em batalha, preservando a captura clássica.

## Mobile
Inclui joystick virtual e botões touch básicos.

## Executar
`npm install` e `npm run dev`.
